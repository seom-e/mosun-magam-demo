# 모선마감 — 발표용

광양지사 모선마감 업무 도구 모음의 **발표용 예시판**입니다.

> ### ⚠ 여기 나오는 자료는 전부 지어낸 것입니다
> 모선명 · 항차 · 날짜 · 담당자 이름 · 연락처 모두 **실제가 아닙니다.**
> 실제 업무 자료는 이 저장소에 들어있지 않습니다.

## 무엇을 보여주는가

`시작.html` 하나로 이번 주 흐름이 순서대로 보입니다.

| | 도구 | 하는 일 |
|---|---|---|
| ① | 스케줄확인 | 모선 · ETB · 다큐마감 확인, 담당자별 보기, 변동 기록 |
| ② | CBF확인 | 마감 · 포탈 자동입력 |
| ③ | 미반입 & 셔틀 | 반입 사전확인 · 셔틀 재반출 |
| ④ | 화물료 | 화물료 · 보안료 신고 |

수시: 위험물DG · 신고현황 · 적하목록정정 · 체크리스트

**스케줄확인**에는 예시 모선 15척이 미리 들어 있어 열면 바로 보입니다.
담당자를 `홍길동 · 김철수 · 이영희` 로 바꿔 누르면 그 사람 모선만 걸러집니다.

## 실제로 쓸 때와 다른 점

발표용은 인터넷 주소로 열리므로, **컴퓨터를 직접 만지는 기능은 빠집니다.**
화면에 `이 PC에서만` 이라고 표시됩니다.

- 미반입 & 셔틀 (별도 프로그램 실행)
- 장금메일 자동 읽기 (아웃룩을 직접 염)
- 신고현황 자료 받기 (파이썬 실행)
- GWCT · KIT 자동조회 (사내 조회 서버)

실제 업무에서는 회사 PC 에 폴더째 두고 `시작.html` 로 열어 씁니다.

## 자료는 어디에 저장되나

화면에 올린 엑셀은 **그 사람 브라우저에만** 저장됩니다.
서버로 가지 않고, 다른 사람에게 보이지 않습니다.
